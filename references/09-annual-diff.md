# 09 · 年度系列差异分析

> 研报库里很多是「每年都发一次」的系列报告（State of AI Report、V-Dem、ACFE RTTN、WorldBank GEP…）。
> 单看某一年的没意思，**把多年摆在一起看**才知道：作者口径怎么变、哪句话被打脸、哪个判断是长期信仰。

---

## 一、三件事

1. **发现** —— 从文件名自动认出「同一份报告的多个年份」（实测全库识别出 **83 个系列**）
2. **对比** —— 三阶段 map-reduce：**分块提炼 → 年度画像 → 跨年度差异**
3. **两种出口** ——
   - ① 用项目自带免费 AI 池直接出报告
   - ② ★ **只导出素材包**，交给用户自己的 AI（不消耗 AI 池）

---

## 二、★★★ 系列识别靠「标题归一化」

```
原文:  20261011_State-of-AI-Report-2026_lowres.pdf
归一:  去日期前缀 → 去年份 → 去语言/清晰度标记 → 去尾部 hash → 小写
结果:  state-of-ai-report
```

**归一化规则**（按顺序）：
1. 去**抓取日期前缀**（`YYMMDD_`）
2. 去**年份**（`2018`~`2030`）
3. 去**语言/清晰度标记**（`_lowres` / `_spanish` / `_portuguese` …）
4. 去**尾部随机 hash**
5. 小写化

### 两个必须的修正（踩过）

| 修正 | 原因 |
|---|---|
| ★ **尾部 hash 必须含数字**才算 hash | 否则会把 `report-to-**nations**` 这类正常尾词误吃掉 → 同一系列被拆成多个变体（实测某报告被拆成 3 组） |
| ★ **`the` 作归组停用词** | 让 `report-to-the-nations` 与 `report-to-nations` 并成一组 |

### 已知限制

- 同一报告**改名幅度大**（如 V-Dem 早期 `dr_2017`、后期 `V-Dem_Democracy_Report_2026`）→
  会被识别成两个系列 → 用**别名表** `TITLE_ALIAS` 处理常见几例。
- 复合命名的章节型报告（如 Stanford HAI 的 `technical-performance-...`）会各自成系列。
- **年份取自文件名**；识别不到年份的文件**跳过**（不会误判）。

## 三、三种用法

### 用法 A：看板（先看有哪些系列）
```bash
python annual_diff.py --root ../reports --index
# 产出：_annual_diff_out/年度报告差异分析_看板.html
```

### 用法 B：只导出素材包（★ 推荐，不烧 AI）
```bash
# 单个系列
python annual_diff.py --root ../reports --dir "reports/科技产业/StateOfAI-人工智能现状报告" --pack

# 批量：给「年份最多」的前 N 个系列各导一份
python annual_diff.py --root ../reports --pack-top 15
```
产出：
- `_annual_diff_out/<系列>_对比素材包.md` —— **可直接粘给任意 AI**，头部自带推荐指令
- `_annual_diff_out/<系列>_素材/*.txt` —— 每个年份一份纯文本，便于单独上传

### 用法 C：用自带 AI 池直接出报告
```bash
python annual_diff.py --root ../reports --dir "<站目录>"
# 产出：<系列>_年度差异分析.md / .html
#      含「逐年新增 / 反转 / 长期主线 / 数字趋势」
```

## 四、★★★ 缓存必须绑内容（踩过）

**坑**：缓存只按「年份」键控 → 用 `--limit-chunks 2` 试跑的**旧结论**，
在完整跑时**被复用** → 输出的分析其实是基于 2 个块的。

**修正**：
| 缓存对象 | 绑定键 |
|---|---|
| **年度画像** | 绑**块数**（chunk 数变了就失效） |
| **跨年差异对比** | 绑**画像指纹**（画像变了就失效） |

★ 一句话：**缓存键必须包含「生成它时用的输入」，否则会静默复用过期结果。**

---

## 五、map-reduce 三阶段

```
阶段 1 · 分块提炼
  每个 PDF → 切块 → 每块调 AI 提炼要点（带缓存，中断重跑只补未完成的块）

阶段 2 · 年度画像
  同一年的所有块要点 → 汇总成「这一年的核心判断 + 关键数字」
  （缓存绑块数）

阶段 3 · 跨年差异
  多年画像 → 对比 → 输出四类结论
  （缓存绑画像指纹）
```

**四类结论**：
1. **逐年新增** —— 今年新出现、去年没有的议题
2. **反转** —— 与上一年**结论相反**的判断（最有价值）
3. **长期主线** —— 每年都强调的（信仰级）
4. **数字趋势** —— 关键指标的年际变化

---

## 六、素材包（给「用户自己的 AI」用）

最短路径：
1. 跑 `--pack-top 15`
2. 打开 `_annual_diff_out/<系列>_对比素材包.md`
3. **整个文件丢给任意 AI** —— 文件头部已写好指令，直接说「按上面的要求分析」

**素材包的设计要点**：
- 数字**保留原始口径**（不做二次换算）
- 指令里写死「**不得凭空推断**，每条结论要能追溯到正文」
- 每个年份的纯文本单独成文件（便于分片上传）

---

## 七、调用 AI 的注意

| 注意 | 说明 |
|---|---|
| `--limit-chunks N` | 省钱试跑（每份报告只取 N 块）—— ★ 但**缓存必须绑块数**，否则污染完整跑 |
| `--dry-run` | 只发现 + 分块，不调 AI |
| `--years 2023,2024` | 只分析指定年份 |
| `--per-year 1` | 每年最多取几份（默认 1） |
| Python 解释器 | ★ 若托管 Python 缺 pypdf → **必须用装了 pypdf 的那个解释器**（显式路径） |
